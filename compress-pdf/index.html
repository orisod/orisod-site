Compress PDF

Reduce the file size of a PDF. Works best for scanned documents or PDFs with lots of images. Everything happens locally in your browser.

⚠️ Good to know before you start: this tool works by converting each page into a compressed image and rebuilding the PDF from those images. This shrinks file size well for scanned pages or photo-heavy documents, but the resulting PDF will no longer have selectable or searchable text. If your PDF is mostly text and you need to keep it searchable, this may not be the right tool for it.
🔒 Processed on your device · No upload · No account · No watermark

Higher = better quality, larger file. Lower = smaller file, more compression.

What does this tool do?

This tool reduces PDF file size by rendering each page as a compressed image and rebuilding the document from those images, similar to how you'd compress a photo. It's most effective on scanned documents, photo-heavy PDFs, or anything where pages are already essentially images — the file size drop can be significant.

When should you use it?

  • You have a scanned document that's too large to email or upload
  • Your PDF is full of photos and the file size is unreasonably large
  • You don't need to select, copy, or search the text in the document
  • A form or platform has a strict file size limit for PDF uploads

Why use Orisod for this?

You control the compression level with a slider and see the before/after file size comparison immediately. Everything happens locally in your browser using PDF.js and jsPDF — your document is never uploaded to a server.

Frequently asked questions

Will I lose the ability to select text?
Yes. Since this tool converts pages to compressed images to achieve real size reduction, the resulting PDF is image-based and text is no longer selectable or searchable.
Is this a good fit for a text-heavy report or contract?
Not ideally — if you need to keep text selectable and searchable, this tool isn't the right choice. It works best for scanned pages or documents that are already essentially images.
How much smaller will my file be?
It varies widely depending on your original PDF and the compression level you choose, but scanned or image-heavy documents often shrink significantly.
Is my PDF uploaded to a server?
No, the entire process happens locally in your browser using JavaScript.
