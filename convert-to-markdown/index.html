What does this tool do?

Paste formatted content — copied from a webpage, a Word document, or Google Docs — into the Rich Text box, or paste raw HTML markup into the HTML Source box, and this tool converts it to clean Markdown as you go: headings, bold and italic, links, images, ordered and unordered lists, blockquotes, code blocks, tables, and strikethrough.

When should you use this tool?

  • Moving a document or article into a Markdown-based wiki, README, or static site
  • Converting a formatted webpage or Google Doc into Markdown for a note-taking app
  • Turning an HTML email or exported HTML file into Markdown you can edit as plain text
  • Quickly converting a table copied from a webpage into a Markdown table

Why Orisod

Conversion uses Turndown, the standard library for HTML-to-Markdown conversion, with its GitHub-Flavored Markdown plugin for tables and strikethrough. Nothing you paste ever leaves your browser.

Frequently asked questions

What's the difference between Rich Text and HTML Source mode?
Rich Text mode accepts a normal paste — the browser carries the formatting from whatever you copied automatically. HTML Source mode is for when you already have raw HTML markup (like view-source output) and want to paste that text directly.
Will tables convert correctly?
Yes — tables convert to GitHub-Flavored Markdown table syntax, which is supported by GitHub, most static site generators, and most Markdown editors.
What happens to images and complex formatting?
Images convert to Markdown image syntax referencing their original source URL. Formatting with no Markdown equivalent (custom fonts, colors, exact spacing) is dropped, since Markdown itself doesn't support it.
Is my content uploaded to a server?
No, the entire process happens locally in your browser using JavaScript.
