What does this tool do?

Upload two PDFs and this tool weaves their pages together — page 1 from File A, page 1 from File B, page 2 from File A, page 2 from File B, and so on — into a single document. A live order preview lists exactly how every page will be arranged before you download. Because pages are copied with their original content intact rather than rasterized, the result stays fully vector and text-selectable.

When should you use this tool?

  • Recombining front-side and back-side scans from a scanner that can't do duplex automatically
  • Fixing a back-side scan that came out in reverse page order (a common quirk of flip-the-stack scanning)
  • Merging two versions of a document where content should alternate page by page
  • Reassembling any two page sequences that need to interleave rather than simply concatenate

Frequently asked questions

What happens if File A and File B have different page counts?
Pages interleave for as long as both files still have pages left; once the shorter file runs out, the remaining pages from the longer file are appended at the end in their own order — nothing is dropped or duplicated.
When should I use "Reverse File B's page order"?
When the back sides were scanned by flipping the whole stack over and feeding it in again — that produces the back-side pages in reverse order, so reversing them here re-aligns each back side with its correct front side.
Will pages come out upside down?
This tool only reorders pages — it doesn't rotate them. If your back-side scans came out rotated 180°, rotate them first with Rotate PDF Pages.
Are my PDFs uploaded to a server?
No, the entire process happens locally in your browser using JavaScript.
