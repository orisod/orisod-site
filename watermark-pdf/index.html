What does this tool do?

This tool stamps a text watermark — like "CONFIDENTIAL", "DRAFT", or your own name — onto every page of a PDF, with full control over position, rotation angle, size, color and opacity. A live preview of page 1 updates as you adjust each setting, so you can see exactly how it'll look before downloading.

When should you use this tool?

  • You're sharing a draft document and want to mark it clearly as not final
  • You need to label a PDF as confidential before sending it externally
  • You're distributing a sample or preview and want to discourage unauthorized reuse
  • You want to brand a document with your name or company before publishing it

Why use Orisod for this?

Adjust text, position, rotation, size, color and opacity with a live preview before you commit — no guessing and re-downloading. The whole process happens locally in your browser using pdf.js for the preview and pdf-lib to build the final file — your document is never uploaded to a server.

Frequently asked questions

Does the watermark apply to every page?
Yes, the same watermark is stamped onto every page of the PDF using the settings you choose.
Can I remove the watermark afterward?
The watermark becomes part of the page content, similar to how watermarks work in other PDF tools. Keep your original file if you might need an unwatermarked copy later.
Can I add a logo image instead of text?
This tool currently supports text watermarks only.
Is my PDF uploaded to a server?
No, the entire process happens locally in your browser using JavaScript.
