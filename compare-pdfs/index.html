What does this tool do?

This tool reads the selectable text out of two PDFs — the same way Extract PDF Text does — splits each into lines, and runs a line-by-line diff to show exactly which lines only appear in File A (removed) and which only appear in File B (added). A summary count sits above the diff, and page markers keep the two documents' page numbers visible throughout.

When should you use this tool?

  • Checking what actually changed between two drafts of a contract or report
  • Confirming a "final" PDF matches the version you approved earlier
  • Spotting accidental edits after a document was re-exported or re-typeset
  • Reviewing a counterparty's revised PDF without reading the whole thing line by line yourself

Why Orisod

Comparison happens entirely in your browser using pdf.js to read the text and a client-side line diff to compare it. Neither PDF is ever uploaded anywhere.

Frequently asked questions

Does this compare the visual layout of the two PDFs?
No — this tool compares the underlying extracted text only, not images, fonts, page layout, or formatting. Two PDFs that look identical but have differently ordered text, or that were re-typeset with the same wording, may still show differences here.
What does "Ignore whitespace differences" do?
It trims extra spaces at the start/end of each line and collapses repeated spaces before comparing, so purely cosmetic spacing changes don't show up as false differences.
Why does it say one of my PDFs has no selectable text?
If a PDF is a scanned image without a real text layer, there's nothing to extract or compare — run it through OCR PDF first to give it searchable text.
Is there a size limit?
Very long documents are compared up to the first 4,000 lines of each file to keep the comparison fast in your browser; you'll see a note if a file was truncated.
Are my PDFs uploaded to a server?
No, the entire process happens locally in your browser using JavaScript.
