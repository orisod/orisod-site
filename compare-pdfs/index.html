A text comparison, not a visual PDF diff

The tool extracts selectable text from each PDF, divides it into lines and compares the sequences. Lines found only in File A appear as removed, while lines found only in File B appear as added. Page markers remain visible and a summary counts the differences. Extraction order depends on how each PDF stores its text, so results are clues for review rather than proof that every visual or semantic change was found.

When line-level changes need a quick review

  • Review wording changes between contract or report drafts
  • Check whether a final PDF contains the same extracted wording as an approved copy
  • Spot line changes introduced during export or typesetting
  • Focus a manual PDF review on sections where extracted text differs

Frequently asked questions

Does this compare the visual layout of the two PDFs?
No. Images, fonts, color, layout, annotations and other visual or interactive changes are outside this comparison. Even identical wording can appear different when the two PDFs store or order their text objects differently.
What does "Ignore whitespace differences" do?
It removes leading and trailing spaces and reduces repeated spaces before comparing each line. This hides simple spacing differences, but it does not normalize punctuation, capitalization or wording.
Why does it say one of my PDFs has no selectable text?
A scanned PDF may contain only page images and no text layer. Apply OCR first if you are authorized to process the document, then verify the recognized text because OCR can introduce errors.
Is there a size limit?
Each document is compared through its first 4,000 extracted lines. The tool displays a notice when this limit truncates a file, so the result should not be treated as a complete comparison in that case.
Are my PDFs uploaded to a server?
No. Extraction and comparison happen locally in your browser.
