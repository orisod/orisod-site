Text to PDF

Paste or type plain text, choose basic page and font settings, and create a paginated PDF with selectable text.

🔒 Processed on your device · No upload · No account · No watermark

Build a simple PDF from unformatted text

Enter plain text, choose a page size and available font, then set the type size. The tool wraps the lines and adds pages as needed. The output stores text as PDF text rather than a screenshot, which makes supported characters selectable and searchable. It is a basic document generator, not a word processor with headings, images or rich formatting.

When plain text is all you need

  • Share notes, a script or a draft as a simple PDF
  • Create a PDF without opening a word processor
  • Submit plain text to a system that requires PDF
  • Paginate a long block of unformatted text consistently

Frequently asked questions

Does this support bold, italics, or headings?
No. The PDF input is plain text, so bold, italics, headings, lists and images are not interpreted as formatting. Use a document editor when the layout needs those features.
Is the text in the PDF selectable and searchable?
Yes, when the selected font supports the characters used. The content is written as PDF text rather than rendered as an image, so it can normally be selected, searched and copied.
Is there a length limit?
The tool does not impose a fixed text-length quota, but browser memory and processing time create practical limits for very large input. Long text is paginated automatically.
Is my text uploaded to a server?
No. The text and generated PDF remain in your browser.
