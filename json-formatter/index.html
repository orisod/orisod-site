JSON Formatter

Format, validate, and minify JSON right in your browser. Paste JSON below, adjust indentation or sort keys, and get an exact line and column for any syntax error — nothing you paste is ever uploaded.

🔒 Processed on your device · Never sent anywhere · Not stored

What does a JSON formatter do?

JSON (JavaScript Object Notation) is a plain-text data format, but it's picky about syntax — a missing quote, a trailing comma, or a single-quoted string will make it invalid. This tool runs your JSON through your browser's own strict JSON parser, then either pretty-prints it with readable indentation or minifies it into a single compact line, and points out exactly where any syntax error is if parsing fails.

When should you use this tool?

  • You're debugging an API response and need to read a wall of minified JSON
  • You have a config file or payload with inconsistent or missing indentation
  • You want to compare two JSON payloads and need their keys in the same order first
  • You need to shrink JSON before pasting it somewhere with a size limit

Frequently asked questions

Does this validate my JSON?
Yes — clicking Format or Minify runs your input through strict JSON parsing. If there's a syntax error, you'll see the exact line and column instead of just a generic "invalid JSON" message.
What happens to duplicate keys in an object?
JSON.parse keeps the last occurrence of a duplicate key and discards the earlier ones — that's standard behavior for every JSON parser, not something this tool changes.
Does sorting keys change my data?
No — it only reorders keys within each object alphabetically. Values, array order, and nested structure stay exactly the same. It's mainly useful for comparing two JSON payloads that should be identical except for key order.
Is there a size limit?
No hard limit is enforced by this tool — the practical ceiling is how much text your browser can hold in memory, which is comfortably megabytes of JSON on any modern device.
