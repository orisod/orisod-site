What does this tool do?

Pick a color visually or type a value into any field — HEX, RGB, or HSL — and the other two update instantly. An opacity slider adds alpha channel support to all three formats (8-digit HEX, rgba(), and hsla()). This tool converts a color you choose or type — it doesn't extract a color from an uploaded image (for that, see Color Picker from Image below).

When should you use this tool?

  • You have a HEX value from a design file and need the RGB or HSL equivalent for code
  • You want to fine-tune a color's lightness or saturation using HSL, then get the HEX for CSS
  • You need a semi-transparent color and want the exact rgba()/hsla() syntax
  • You're translating a color between a design tool and a codebase that expects a different format

Why Orisod

Frequently asked questions

Does the native color picker support transparency?
No — browsers' built-in color picker only selects an opaque color, which is why opacity is a separate slider here. The slider's value combines with the picker's color to produce the alpha-aware HEX/RGB/HSL output.
What formats can I type directly into each field?
HEX accepts 3, 4, 6, or 8 hex digits, with or without a leading #. RGB accepts rgb(r, g, b) or rgba(r, g, b, a). HSL accepts hsl(h, s%, l%) or hsla(h, s%, l%, a). An invalid value shows an error instead of silently guessing.
Does this tool support CMYK?
No — CMYK is a print-oriented format without one universally correct conversion formula (the "right" RGB-to-CMYK math depends on the specific printer/ink profile), so it's out of scope for a browser-based color tool aimed at web/CSS use.
Is anything sent to a server?
No, the entire process happens locally in your browser using JavaScript.
