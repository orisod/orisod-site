PDF to Word

Extract selectable PDF text into a .docx file for Word or Google Docs. The conversion runs locally in your browser.

ℹ️ Text-only conversion: this pulls the selectable text out of the PDF and rebuilds it as editable paragraphs in a .docx file. It does not preserve the original layout, fonts, or images. Tables are flattened into plain text lines (columns separated by spaces), not rebuilt as real, editable Word tables. This works best for text-heavy documents like letters, reports, and contracts. For anything with complex layout, expect to do some manual cleanup afterward.
🔒 Processed on your device · No upload · No account · No watermark

From selectable PDF text to an editable document

The tool reads selectable text from each PDF page, groups it into lines and writes those lines to a .docx file. You can then open the result in Microsoft Word, Google Docs or another compatible editor. This is a text extraction workflow rather than a visual reconstruction: it does not reproduce images, exact fonts, spacing or multi-column layouts, and table cells become space-separated text instead of an editable grid.

Best suited to text-first documents

  • Edit wording from a mostly text-based PDF in Word
  • Reuse text from a PDF without typing the entire document again
  • Recover text from a simple PDF report, letter or contract
  • Create a working draft that you can clean up and reformat

Frequently asked questions

Will tables come through as real Word tables?
No. The converter reads PDF text, not the table structure. Each source row may appear as a line with spaces between its values, so you will need to rebuild any editable table in Word.
Will images or the original layout be preserved?
No. The output contains selectable text but does not recreate images, exact fonts, columns or precise page spacing. Use it as an editable draft rather than a visual duplicate.
Why is my output empty or missing text?
A scan may contain only page images and no selectable text layer. This tool does not perform OCR, so such pages can produce little or no output. Text encoding and reading order in unusual PDFs may also affect extraction.
Is my PDF uploaded to a server?
No. JavaScript reads the PDF and builds the .docx locally in your browser.
