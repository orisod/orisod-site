    Help and details

    Help and common issues

    1. Choose the country and type the phone number the way you'd dial it there, or paste it with its country code.
    2. Add a message if you want one. It's typed into the chat for you, and you decide whether to send it.
    3. Open the chat, copy the link, share it or generate a QR code to scan or download.
    • Pick the country of the phone number. You can search by name or by calling code.
    • Type it as you'd dial it in that country, or paste it with + and the country code. Spaces, dashes and brackets are fine.
    • The number needs a WhatsApp account. Landlines work only if they're registered with WhatsApp Business.
    • On a phone the link opens the WhatsApp app. On a computer, WhatsApp shows its own page first, then opens WhatsApp Desktop or WhatsApp Web.

    Privacy and sharing

    • Nothing is sent automatically: WhatsApp opens the chat with your message typed in, and you press send.
    • Orisod does not store or receive the number or message. A QR scanner can read both from the generated code. WhatsApp receives them when the resulting link is opened.
    • The link doesn't expire, and anyone who has it can open a chat with that number.
    • This page remembers the last country you chose on this device. It doesn't save the number or the message.

    What a wa.me link is

    A wa.me link is WhatsApp's own short address for starting a chat. It holds the phone number in international format, using digits only, and it can carry a message in its text parameter. Opening it starts a chat with that number without saving it to your contacts first, and the message appears in the typing box, ready to send or edit.

    When to use it

    • Message a number once, like a delivery driver or a seller, without adding it to your contacts
    • Put a chat button on a website, an email signature or a social media profile
    • Print a QR code on a card, a flyer or a shop counter so customers can write to you
    • Send customers a ready-made message, like a booking request, that they only need to send

    Emoji and formatting

    Select text and choose a format. Without a selection, the markers are inserted at the cursor. WhatsApp does not support underline.

    Line breaks and emojis are preserved. Use the buttons above the message for bold, italic, strikethrough, monospace and emoji, or type WhatsApp's markers yourself, such as *bold* or `inline code`.

    Choose an emoji to insert at the cursor. For more options, use your device's emoji keyboard.

    Emojis can make the encoded link longer, especially when one emoji is made from several characters.

    Frequently asked questions

    Does the person see that the message came from a link?
    No. The message is typed into the chat as if you'd written it, and it only reaches them when you press send. They see your WhatsApp number, as with any chat you start.
    Why does WhatsApp say the phone number shared via URL is invalid?
    Usually the number doesn't have a WhatsApp account, or the country code or a digit is wrong. Check the number shown under the field. For Argentine mobiles, check that there's a 9 after +54.
    Can I create a link for a WhatsApp group?
    No. Group invite links are created in WhatsApp itself, from the group's settings. A wa.me link always opens a chat with one phone number, or lets you choose the chat when there's no number.
    Does the link stop working after a while?
    No. A wa.me link doesn't expire. It keeps working as long as the number has a WhatsApp account, so make a new one if the number or the message changes.
