What does this tool do?

This tool lets you mark up a PDF the way you would a paper printout: click anywhere to drop in a text box, or drag across existing text to highlight, underline, or strike it through. Everything you add is a preview until you click "Save & Download," which draws it permanently into the page as real content.

When should you use this tool?

  • You're reviewing a document and want to mark up sections without printing it
  • You need to add a note, correction, or comment directly onto a PDF page
  • You want to highlight the important parts of a contract or report before sharing it

Frequently asked questions

Can I highlight text on a scanned PDF?
Only if it has a real, selectable text layer. A plain scan has none to select — if that's the case, this tool tells you so and only offers text boxes, which work on any PDF regardless of whether its text is selectable. Run it through OCR PDF first to add a searchable, selectable text layer to a scan.
Can I undo a mistake?
Yes — everything you add appears in the "Pending changes" list with its own delete button, or use "Clear all" to start over. Nothing is written into the actual PDF until you click "Save & Download."
Can I change the highlight color?
Not in this version — highlights use a standard yellow, and underline/strikethrough use red, matching common markup conventions.
Is my PDF uploaded to a server?
No, the entire process happens locally in your browser using JavaScript.
