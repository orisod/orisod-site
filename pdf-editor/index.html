Add visible markup without changing the source wording

Click a page to place a text box or drag over selectable text to highlight, underline or strike it through. Changes remain in a pending list until you save. Export draws the new marks onto the PDF page. They become visible page content, but that does not make the file tamper-proof or securely redact anything underneath.

Frequently asked questions

Can I highlight text on a scanned PDF?
Highlighting requires a selectable text layer. A plain scan has none, although text boxes can still be placed on its pages. Apply OCR PDF first if you need selectable text, then verify the recognized layer before marking it.
Can I undo a mistake?
Yes, before saving. Remove individual items from “Pending changes” or clear the list. After download, use the original PDF to start over if you need to undo content already written into the exported copy.
Can I change the highlight color?
No. This version uses yellow for highlights and red for underline or strike-through marks.
Is my PDF uploaded to a server?
No. JavaScript previews and writes the changes inside your browser.
