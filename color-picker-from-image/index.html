What does this tool do?

This tool lets you click any point on an uploaded image and instantly get that exact pixel's color as a HEX code (like #3b82f6) and RGB value (like rgb(59, 130, 246)) — both ready to copy and use in CSS, design software, or anywhere else you need a precise color match.

When should you use this tool?

  • You want to match a color from a photo or screenshot in your website or design
  • You're building a brand palette based on colors in a logo or photo
  • You need the exact HEX code of a color you can only see, not measure
  • You're comparing colors across multiple points in an image

Why use Orisod for this?

Click anywhere on the image for an instant reading, with one-click copy for both HEX and RGB formats. Your recent picks are kept visible so you can compare several colors from the same image. Everything happens locally in your browser — your image is never uploaded to a server.

Frequently asked questions

How accurate is the color reading?
It reads the exact pixel value at the point you click, so it's as accurate as the image itself — though compressed images (like JPG) can have slight color variation between neighboring pixels.
Can I pick multiple colors from the same image?
Yes, keep clicking different points — your recent picks are shown as a row of swatches you can click to bring back.
Is my image uploaded anywhere?
No, the entire process happens locally in your browser using the Canvas API.
What formats does this support?
JPG, PNG, WEBP and other common image formats your browser can display.
