What makes a password strong?

A password's strength comes down to how many possible combinations an attacker would have to try — which depends on both its length and how many different characters it could contain. A long, fully random password drawing from a large character set (uppercase, lowercase, numbers, and symbols) is far harder to guess or brute-force than a short one, even one with unusual substitutions like "P@ssw0rd."

When should you use this tool?

  • You're creating a new account and want a genuinely random password instead of a memorable-but-guessable one
  • You're setting up a password manager and need strong passwords for every site
  • A site requires a password meeting specific character requirements (the toggles here match common length/character rules)

Why Orisod

This generator uses your browser's cryptographically secure random number generator (the same one used for encryption keys), not a weaker pseudo-random function. The password is generated entirely on your device — it's never transmitted anywhere, and closing or reloading the page discards it completely.

Frequently asked questions

Is this password actually random?
Yes — it's generated using the Web Crypto API's crypto.getRandomValues(), a cryptographically secure source of randomness, not Math.random(), which isn't designed for security-sensitive use.
Does this tool store or remember my passwords?
No — nothing is saved anywhere, on this device or any server. Once you leave or reload the page, the password is gone unless you've copied and saved it yourself.
What does "exclude ambiguous characters" do?
It removes characters that are easy to misread or mistype, like the digit 0 vs. the letter O, or 1 vs. l vs. I. Useful if you need to type the password by hand rather than copy-paste it — at a small cost to the total character pool.
Is my password sent to a server?
No, the entire process happens locally in your browser using JavaScript.
