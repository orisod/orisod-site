¿Qué hace esta herramienta?

La herramienta procesa el HTML que pegas o seleccionas, incluidos los estilos en línea y los bloques <style>, y muestra una vista previa en tiempo real antes de crear el PDF. Si el contenido ocupa más de una página, se divide automáticamente.

¿Cuándo usar esta herramienta?

  • Tienes un fragmento HTML, plantilla de factura o informe y necesitas una versión en PDF
  • Quieres previsualizar rápidamente cómo se verá un HTML/CSS antes de generar un documento
  • Estás generando un documento simple desde código y no quieres instalar nada
  • Necesitas archivar una página HTML con estilo como un PDF fijo y compartible

Preguntas frecuentes

¿Puedo convertir una página web introduciendo su URL?
No. La herramienta convierte el código HTML que pegas o seleccionas, pero no puede obtener por sí sola una página alojada en otro sitio porque eso requeriría un servidor. Copia el código fuente de la página y pégalo aquí.
¿Por qué algunas imágenes no aparecen en el PDF?
Las imágenes cargadas desde otros sitios web deben permitir acceso de origen cruzado (CORS). Si un sitio lo bloquea, el navegador no puede leer los datos de la imagen para incluirla en el PDF.
¿Puede una línea de texto quedar dividida entre dos páginas?
En raras ocasiones, sí — los saltos de página son un corte recto a una altura fija, no una paginación consciente del diseño. Si una línea de texto denso cae justo en ese corte, puede quedar dividida visualmente entre el final de una página y el inicio de la siguiente. El contenido con espaciado natural (títulos, elementos de lista, saltos de párrafo) casi siempre evita esto.
¿Se ejecutan las etiquetas <script> de mi HTML?
No. Por seguridad, los scripts no se ejecutan; solo se procesa la estructura HTML y los estilos CSS.
¿Se envía mi contenido a algún servidor?
No. Todo se procesa localmente en tu navegador mediante JavaScript; el archivo permanece en tu dispositivo.
