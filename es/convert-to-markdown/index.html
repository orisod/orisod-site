¿Qué hace esta herramienta?

Pega contenido con formato — copiado de una página web, un documento de Word o Google Docs — en el cuadro de Texto enriquecido, o pega código HTML directamente en el cuadro de Código HTML, y esta herramienta lo convierte a Markdown limpio al instante: encabezados, negrita y cursiva, enlaces, imágenes, listas ordenadas y no ordenadas, citas, bloques de código, tablas y texto tachado.

¿Cuándo usar esta herramienta?

  • Trasladar un documento o artículo a una wiki, README o sitio estático basado en Markdown
  • Convertir una página web con formato o un Google Doc a Markdown para una app de notas
  • Convertir un correo HTML o un archivo HTML exportado en Markdown editable como texto plano
  • Convertir rápidamente una tabla copiada de una web en una tabla Markdown

Preguntas frecuentes

¿Cuál es la diferencia entre el modo Texto enriquecido y Código HTML?
El modo Texto enriquecido acepta un pegado normal — el navegador transporta automáticamente el formato de lo que copiaste. El modo Código HTML es para cuando ya tienes marcado HTML crudo (como la salida de "ver código fuente") y quieres pegar ese texto directamente.
¿Las tablas se convierten correctamente?
Sí — las tablas se convierten a la sintaxis de tablas de Markdown estilo GitHub, compatible con GitHub, la mayoría de generadores de sitios estáticos y la mayoría de editores de Markdown.
¿Qué pasa con las imágenes y el formato complejo?
Las imágenes se convierten a la sintaxis de imagen de Markdown, referenciando su URL de origen original. El formato sin equivalente en Markdown (fuentes personalizadas, colores, espaciado exacto) se descarta, ya que el propio Markdown no lo admite.
¿Se sube mi contenido a un servidor?
No, todo el proceso ocurre localmente en tu navegador con JavaScript.
