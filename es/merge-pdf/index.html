Unir PDF

Combina varios archivos PDF en un solo documento. Todo ocurre localmente en tu navegador — tus archivos nunca se suben a ningún lugar.


Los archivos se combinan en el orden mostrado arriba. Usa las flechas para reordenarlos.

¿Qué hace esta herramienta?

Esta herramienta combina dos o más archivos PDF en un único documento PDF, manteniendo el texto, las imágenes y el formato original de cada página exactamente como estaban — nada se rasteriza ni se vuelve a renderizar como imagen. El resultado es un PDF real, de calidad editable, no una copia con aspecto escaneado.

¿Cuándo deberías usarla?

  • Tienes varios informes, facturas o capítulos en PDF por separado y necesitas un archivo combinado
  • Estás armando un portafolio o expediente de solicitud a partir de varios documentos
  • Escaneaste un documento en partes y necesitas combinar las páginas en un solo PDF
  • Quieres enviar varios documentos relacionados como un solo adjunto

¿Por qué usar Orisod para esto?

La unión ocurre completamente en tu navegador usando pdf-lib — tus PDF nunca se suben a un servidor. Puedes reordenar los archivos antes de unirlos con las flechas arriba/abajo, eliminar cualquier archivo que no quieras incluir, y el documento final conserva la selección de texto completa y la calidad original.

Preguntas frecuentes

¿Unir afecta la calidad o el texto de mis PDF?
No. A diferencia de herramientas que primero convierten las páginas en imágenes, esta herramienta une el contenido real del PDF — el texto sigue siendo seleccionable y buscable, y la calidad de las imágenes no cambia.
¿Puedo cambiar el orden de los archivos?
Sí, usa las flechas arriba y abajo junto a cada archivo para reordenarlos antes de unirlos.
¿Hay un límite de cuántos PDF puedo unir?
No hay un límite fijo — puedes combinar tantos archivos como la memoria de tu navegador pueda manejar cómodamente.
¿Se suben mis archivos a un servidor?
No. Todo el proceso de unión se ejecuta localmente en tu navegador usando JavaScript — nada se envía a ningún lugar.
