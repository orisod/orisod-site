¿Qué es la codificación de imágenes en Base64?

Base64 es una forma de representar datos binarios (como un archivo de imagen) como texto plano. Codificar una imagen en Base64 te permite incrustarla directamente dentro de HTML, CSS o JSON — como un "URI de datos" — en lugar de enlazar a un archivo de imagen separado. Esto es común para íconos pequeños, imágenes en línea de correos electrónicos, o para evitar solicitudes HTTP adicionales.

¿Cuándo deberías usar esta herramienta?

  • Estás incrustando una imagen pequeña directamente en HTML o CSS sin un archivo separado
  • Necesitas incluir una imagen dentro de un payload JSON o una solicitud a una API
  • Estás creando una plantilla de correo electrónico que requiere imágenes en línea
  • Tienes una cadena Base64 y necesitas ver o descargar la imagen real que representa

¿Por qué usar Orisod para esto?

Ambas direcciones — codificar y decodificar — ocurren por completo en tu navegador usando JavaScript. Tu imagen o datos Base64 nunca se envían a un servidor. La salida incluye el prefijo completo del URI de datos, listo para pegar directamente en una etiqueta <img src="..."> o en un background-image de CSS.

Preguntas frecuentes

¿La codificación Base64 aumenta el tamaño del archivo?
Sí, el texto Base64 es aproximadamente un 33% más grande que el archivo binario original, por lo que es más adecuado para imágenes pequeñas, no para fotos grandes.
¿Puedo pegar una cadena Base64 sin el prefijo "data:image/..."?
Sí, el decodificador intentará detectar el tipo de imagen automáticamente si pegas solo los caracteres Base64 sin procesar.
¿Se sube mi imagen o mis datos Base64 a algún lugar?
No, tanto la codificación como la decodificación ocurren localmente en tu navegador usando JavaScript.
¿Qué formatos de imagen son compatibles?
JPG, PNG, WEBP, GIF y la mayoría de los formatos comunes que tu navegador puede leer.
