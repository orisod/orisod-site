Selector de color de imagen

Sube una imagen y haz clic en cualquier lugar para obtener el código de color HEX y RGB exacto en ese punto. Todo ocurre localmente en tu navegador.

🔒 Procesado en tu dispositivo · Sin subir archivos · Sin cuenta · Sin marca de agua
HEX: ¡Copiado!
RGB: ¡Copiado!
Haz clic en cualquier parte de la imagen para muestrear un color. Los colores elegidos recientemente aparecen abajo.

¿Qué hace esta herramienta?

Esta herramienta te permite hacer clic en cualquier punto de una imagen subida y obtener instantáneamente el color exacto de ese píxel como código HEX (como #3b82f6) y valor RGB (como rgb(59, 130, 246)) — ambos listos para copiar y usar en CSS, software de diseño o donde sea que necesites una coincidencia de color precisa.

¿Cuándo deberías usar esta herramienta?

  • Quieres igualar un color de una foto o captura de pantalla en tu sitio web o diseño
  • Estás creando una paleta de marca basada en los colores de un logo o foto
  • Necesitas el código HEX exacto de un color que solo puedes ver, no medir
  • Estás comparando colores entre varios puntos de una imagen

¿Por qué usar Orisod para esto?

Haz clic en cualquier parte de la imagen para una lectura instantánea, con copia de un clic tanto para HEX como para RGB. Tus selecciones recientes se mantienen visibles para que puedas comparar varios colores de la misma imagen. Todo ocurre localmente en tu navegador — tu imagen nunca se sube a un servidor.

Preguntas frecuentes

¿Qué tan precisa es la lectura de color?
Lee el valor exacto del píxel en el punto donde haces clic, así que es tan preciso como la propia imagen — aunque las imágenes comprimidas (como JPG) pueden tener una ligera variación de color entre píxeles vecinos.
¿Puedo elegir varios colores de la misma imagen?
Sí, sigue haciendo clic en distintos puntos — tus selecciones recientes se muestran como una fila de muestras en las que puedes hacer clic para recuperarlas.
¿Se sube mi imagen a algún lugar?
No, todo el proceso ocurre localmente en tu navegador usando la API Canvas.
¿Qué formatos son compatibles?
JPG, PNG, WEBP y otros formatos de imagen comunes que tu navegador pueda mostrar.
