Comprimir PDF

Reduce el tamaño de archivo de un PDF. Funciona mejor con documentos escaneados o PDF con muchas imágenes. Todo ocurre localmente en tu navegador.

⚠️ Bueno saberlo antes de empezar: esta herramienta funciona convirtiendo cada página en una imagen comprimida y reconstruyendo el PDF a partir de esas imágenes. Esto reduce bien el tamaño en páginas escaneadas o documentos con muchas fotos, pero el PDF resultante ya no tendrá texto seleccionable ni buscable. Si tu PDF es sobre todo texto y necesitas que siga siendo buscable, esta puede no ser la herramienta adecuada.
🔒 Procesado en tu dispositivo · Sin subir archivos · Sin cuenta · Sin marca de agua

Más alto = mejor calidad, archivo más grande. Más bajo = archivo más pequeño, más compresión.

¿Qué hace esta herramienta?

Esta herramienta reduce el tamaño de un PDF renderizando cada página como una imagen comprimida y reconstruyendo el documento a partir de esas imágenes, de forma similar a comprimir una foto. Es más eficaz en documentos escaneados, PDF con muchas fotos, o cualquier cosa donde las páginas ya son esencialmente imágenes — la reducción de tamaño puede ser significativa.

¿Cuándo deberías usarla?

  • Tienes un documento escaneado demasiado grande para enviar por correo o subir
  • Tu PDF está lleno de fotos y el tamaño de archivo es excesivo
  • No necesitas seleccionar, copiar ni buscar el texto del documento
  • Un formulario o plataforma tiene un límite estricto de tamaño para subir PDF

¿Por qué usar Orisod para esto?

Controlas el nivel de compresión con un deslizador y ves la comparación de tamaño antes/después al instante. Todo ocurre localmente en tu navegador usando PDF.js y jsPDF — tu documento nunca se sube a un servidor.

Preguntas frecuentes

¿Perderé la capacidad de seleccionar texto?
Sí. Como esta herramienta convierte las páginas en imágenes comprimidas para lograr una reducción de tamaño real, el PDF resultante se basa en imágenes y el texto ya no es seleccionable ni buscable.
¿Es adecuada para un informe o contrato con mucho texto?
No es lo ideal — si necesitas mantener el texto seleccionable y buscable, esta herramienta no es la opción correcta. Funciona mejor con páginas escaneadas o documentos que ya son esencialmente imágenes.
¿Cuánto se reducirá mi archivo?
Varía mucho según tu PDF original y el nivel de compresión que elijas, pero los documentos escaneados o con muchas imágenes suelen reducirse significativamente.
¿Se sube mi PDF a un servidor?
No, todo el proceso ocurre localmente en tu navegador usando JavaScript.
