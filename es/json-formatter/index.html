Formateador de JSON

Formatea, valida y minifica JSON directamente en tu navegador. Pega el JSON abajo, ajusta la sangría u ordena las claves, y obtén la línea y columna exactas de cualquier error de sintaxis — nada de lo que pegas se sube a ningún servidor.

🔒 Procesado en tu dispositivo · Nunca se envía a ningún sitio · No se guarda

¿Qué hace un formateador de JSON?

JSON (JavaScript Object Notation) es un formato de texto plano, pero es estricto con la sintaxis — una comilla que falta, una coma sobrante o una cadena entre comillas simples lo vuelven inválido. Esta herramienta procesa tu JSON con el analizador JSON estricto de tu propio navegador, y luego lo formatea con sangría legible o lo minifica en una sola línea compacta, señalando exactamente dónde está el error de sintaxis si el análisis falla.

¿Cuándo usar esta herramienta?

  • Estás depurando una respuesta de API y necesitas leer un bloque de JSON minificado
  • Tienes un archivo de configuración o payload con sangría inconsistente o inexistente
  • Quieres comparar dos payloads JSON y necesitas que sus claves estén en el mismo orden
  • Necesitas reducir el tamaño del JSON antes de pegarlo en algún sitio con límite de caracteres

Por qué Orisod

El formateo y la validación funcionan con las funciones nativas JSON.parse() y JSON.stringify() de tu navegador — el mismo motor JSON que ya incluye cada navegador. Nada de lo que pegas se transmite a ningún sitio, así que es seguro usarlo con respuestas de API reales, archivos de configuración o cualquier otra cosa que no quieras que salga de tu equipo.

Preguntas frecuentes

¿Esta herramienta valida mi JSON?
Sí — al hacer clic en Formatear o Minificar, tu entrada pasa por un análisis JSON estricto. Si hay un error de sintaxis, verás la línea y columna exactas en lugar de un mensaje genérico de "JSON inválido".
¿Qué pasa con las claves duplicadas en un objeto?
JSON.parse conserva la última aparición de una clave duplicada y descarta las anteriores — así se comporta cualquier analizador JSON, no es algo que esta herramienta cambie.
¿Ordenar las claves cambia mis datos?
No — solo reordena las claves dentro de cada objeto alfabéticamente. Los valores, el orden de los arrays y la estructura anidada se mantienen exactamente igual. Es útil sobre todo para comparar dos payloads JSON que deberían ser idénticos salvo por el orden de las claves.
¿Hay un límite de tamaño?
Esta herramienta no impone ningún límite — el límite práctico es la cantidad de texto que tu navegador puede mantener en memoria, que en cualquier dispositivo moderno equivale cómodamente a varios megabytes de JSON.
