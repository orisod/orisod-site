Analiza JSON antes de cambiar su presentación

Pega JSON para validarlo con el analizador estricto del navegador y después mostrarlo con dos espacios, cuatro o tabulaciones, o minificarlo en una línea. Los errores se informan con los detalles de ubicación disponibles. Como primero se convierte en valores JavaScript, las claves duplicadas pueden colapsar y ciertos números normalizarse; usa un analizador especializado si necesitas conservar esas diferencias.

Preguntas frecuentes

¿Esta herramienta valida mi JSON?
Sí. Formatear y Minificar usan análisis JSON estricto. Los detalles de ubicación dependen del motor y del mensaje que expone, por lo que línea y columna pueden variar entre navegadores.
¿Qué pasa con las claves duplicadas en un objeto?
Al analizar con JSON.parse, la última aparición normalmente reemplaza las claves anteriores del mismo nombre. Esos valores ya no pueden recuperarse, así que inspecciona datos no confiables antes de formatear si importan los duplicados.
¿Ordenar las claves cambia mis datos?
Cambia el orden de claves JSON, pero conserva el orden de arrays y la estructura analizada. El análisis puede haber colapsado duplicados o normalizado números. No uses esa salida para firmas ni comparaciones de bytes.
¿Hay un límite de tamaño?
La interfaz no fija una cuota para JSON. La capacidad depende de memoria, estructura y costo de análisis; datos enormes o muy anidados pueden ralentizar o cerrar la pestaña.
