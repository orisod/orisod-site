Leer en voz alta

Pega tu texto abajo y haz que se lea en voz alta directamente en tu navegador: elige una voz, ajusta la velocidad y el tono, y sigue la lectura mientras cada frase se resalta.

⚠️ No se encontró ninguna voz en español instalada en tu dispositivo. La lista de arriba muestra las voces que tu navegador tiene disponibles, que solo están en otros idiomas: Orisod no puede añadir una voz en español que tu sistema no tenga.
🔒 Sin subidas por parte de Orisod · Sin cuenta · No se almacena
Qué es realmente esto: Leer en voz alta usa el motor de texto a voz integrado de tu propio navegador para leer tu texto en voz alta, en vivo, aquí mismo en esta página. No puede generar ni exportar un archivo de audio descargable (un MP3, por ejemplo): la API Web Speech en la que se basa el navegador solo admite reproducción en vivo, no exportación de audio. Las voces disponibles dependen totalmente de tu dispositivo y navegador, no de Orisod: un teléfono, una Mac y una PC con Windows normalmente ofrecerán voces distintas, y no podemos añadir, garantizar ni mejorar ninguna voz o idioma concreto que no esté ya instalado en tu sistema.
No compatible con este navegador. Leer en voz alta necesita la API Web Speech, que este navegador no ofrece. Prueba con una versión reciente de Chrome, Edge, Safari o Firefox.

Texto a voz en vivo con resaltado de oraciones

Pega texto, selecciona una voz disponible y ajusta velocidad o tono antes de reproducir. La oración actual se resalta mientras la API Web Speech la lee. Las voces y el comportamiento proceden del navegador, el sistema y sus servicios, por lo que disponibilidad, calidad, idiomas y uso de red cambian entre dispositivos. Orisod no sube intencionalmente el texto, pero el proveedor de voz controla cómo se sintetiza.

Escucha, corrige o sigue el texto de otra manera

  • Escuchar un borrador para encontrar ritmo torpe o palabras omitidas
  • Oír notas o un artículo mientras realizas otra tarea
  • Comparar pronunciación con una voz disponible para el idioma
  • Ofrecer otra forma de acceder al contenido escrito

Preguntas frecuentes

¿Puedo descargar el audio como un archivo?
No. La API Web Speech ofrece reproducción en vivo, pero no entrega a Orisod un flujo de audio que pueda exportar como MP3, WAV u otro archivo.
¿Por qué solo veo unas pocas voces, o por qué suenan robóticas?
La lista procede del navegador y del sistema operativo. Las voces instaladas, los valores y la calidad varían; algunas plataformas pueden obtener voces o síntesis mediante servicios en línea. Orisod no las instala.
¿Se envía mi texto a algún servidor?
Orisod no sube intencionalmente el texto. La API Web Speech delega la síntesis al navegador, el sistema o el servicio de voz configurado, y algunas implementaciones pueden usar la red. Consulta la privacidad de tu plataforma antes de introducir contenido sensible.
¿Por qué se detuvo la reproducción a mitad de un texto largo?
La herramienta divide el texto en fragmentos para reducir cortes, pero Web Speech todavía puede detenerse. Prueba Reproducir de nuevo, otra voz instalada, una selección más corta u otro navegador.
