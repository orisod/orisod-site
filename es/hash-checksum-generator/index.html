Generador de Hash y Checksum

Calcula hashes MD5, SHA-1, SHA-256, SHA-384 y SHA-512 de texto o un archivo, y compáralos con un checksum esperado. Todo ocurre localmente en tu navegador.

¿Qué hace esta herramienta?

Escribe o pega texto, o suelta un archivo, y esta herramienta calcula sus hashes MD5, SHA-1, SHA-256, SHA-384 y SHA-512 todos a la vez — sin necesidad de adivinar qué algoritmo usa un checksum publicado. Pega un hash esperado en el campo de verificación y se comprueba automáticamente contra el que coincida en longitud de los cinco calculados.

¿Cuándo usar esta herramienta?

  • Confirmar que un archivo descargado coincide con el checksum publicado por su autor
  • Generar un checksum para compartir junto a un archivo que estás distribuyendo
  • Comparar dos archivos para ver si son idénticos byte a byte sin abrir ninguno
  • Calcular un hash rápido de un fragmento de texto o una contraseña como referencia

Preguntas frecuentes

¿Es seguro usar MD5 o SHA-1?
No para fines de seguridad — ambos tienen debilidades de colisión conocidas y no deben usarse para contraseñas ni firmas digitales. Se incluyen aquí porque las comprobaciones de integridad de archivos (confirmar que una descarga no se corrompió) todavía publican comúnmente checksums MD5 o SHA-1, un caso de uso distinto y no adversarial.
¿Cómo sabe el campo de verificación qué algoritmo comprobar?
Cada algoritmo de hash siempre produce una longitud fija de salida (MD5 son 32 caracteres hexadecimales, SHA-1 son 40, y así sucesivamente), así que la herramienta hace coincidir la longitud del hash que pegaste con el algoritmo correcto automáticamente.
¿Hay un límite de tamaño de archivo?
No hay un límite estricto, pero el archivo completo se carga en memoria para calcular los hashes, así que los archivos extremadamente grandes (varios gigabytes) pueden ser lentos o toparse con los límites de memoria de tu navegador.
¿Se sube mi archivo o texto a un servidor?
No, todo el proceso ocurre localmente en tu navegador con JavaScript.
