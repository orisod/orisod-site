Cómo convertir HTML a PDF (pega el código y obtén el archivo)

Una factura, informe o fragmento HTML puede renderizarse como PDF, pero el resultado depende del CSS compatible, recursos, fuentes, página y método de paginación. Revisa la entrada exacta y trata el PDF como una exportación visual, no como una copia del comportamiento del código.

Cómo funciona la conversión de HTML a PDF

Orisod renderiza HTML y CSS compatibles en un contexto de navegador, captura el resultado y coloca esa salida rasterizada en páginas PDF. No conserva el DOM como contenido PDF estructurado. Las palabras pueden quedar como píxeles; accesibilidad, enlaces, formularios, scripts y encabezados semánticos no sobreviven automáticamente.

Qué puede y qué no puede hacer con un sitio web en vivo

Esta herramienta acepta contenido HTML, no una URL. Copiar solo el código fuente no equivale a cargar el sitio: pueden faltar rutas relativas, estilos, scripts, datos autenticados, shadow DOM, marcos, fuentes y contenido dinámico. Usa un documento autocontenido con recursos locales o incrustados y autorizados cuando necesites reproducibilidad.

Por qué algunas imágenes no aparecen

Las imágenes remotas pueden fallar por CORS, políticas de seguridad, contenido mixto, autenticación, URL vencidas, errores de red o tiempo de captura. Las rutas relativas copiadas también pierden su URL base. Incrusta recursos autorizados cuando sea práctico y espera a que imágenes y fuentes terminen de cargar.

Cómo funciona la paginación para contenido largo

El método actual de Orisod corta el contenido renderizado a alturas fijas. No comprende párrafos, filas, imágenes ni reglas CSS de fragmentación, así que cualquier elemento puede dividirse. Las páginas largas también pueden superar límites de memoria o lienzo del navegador. Revisa cada salto y ajusta la entrada cuando sea necesario.

Elegir el tamaño de página y la orientación

A4 y carta cubren la mayoría de los documentos estándar; Legal es común para contratos y ciertos formularios. La orientación importa más de lo que parece — una tabla ancha o un diseño en orientación horizontal se verá apretado y forzado en una página vertical alta, mientras que la vertical le sienta bien al contenido de texto normal. Acertar con estos ajustes antes de convertir ahorra tener que volver a descargar después.

Prepara una factura autocontenida

Para una factura HTML, incrusta el logotipo autorizado, incluye CSS y fuentes, define el papel y verifica los totales. Compara PDF y vista previa, atendiendo a saltos, filas cortadas, imágenes ausentes y selección de texto. Conserva el HTML y los datos como fuente.

Verifica algo más que la vista previa

¿Puedo convertir un sitio por URL? No con esta herramienta. Copiar el código puede resultar incompleto porque la página depende de recursos externos y dinámicos.

¿Por qué faltan imágenes? CORS es una posibilidad; revisa también rutas relativas, autenticación, CSP, contenido mixto, errores de carga y tiempo de captura.

¿Puede cortarse contenido? Sí. El corte fijo puede dividir texto, imágenes y filas sin importar el espaciado. Revisa todas las páginas.
