Añadir Sellos a un PDF

Elige un sello predefinido o una etiqueta corta, colócalo en una página PDF y revisa el resultado antes de descargar.

🔒 Procesado en tu dispositivo · Sin subidas · Sin cuenta
1. Elige un sello
2. Elige la página y haz clic para colocarlo
170pt
Haz clic en cualquier parte de la página para mover el sello ahí.

Coloca una etiqueta de estado visible en una página

Elige APROBADO, BORRADOR o CONFIDENCIAL, o escribe una etiqueta corta. Después selecciona una página del PDF y haz clic en la posición deseada. La vista previa muestra el lugar y tamaño antes de exportar. El sello comunica un estado a los lectores, pero no impone confidencialidad, permisos ni reglas de aprobación.

Dónde resulta útil un sello documental

  • Indicar que un documento superó una revisión interna
  • Marcar una copia de trabajo como BORRADOR para distinguirla de la final
  • Mostrar CONFIDENCIAL como recordatorio sin depender del sello para la seguridad
  • Añadir un estado corto propio del flujo de trabajo

Preguntas frecuentes

¿Puedo sellar más de una página?
La herramienta coloca un sello en una página por pasada. Para marcar otra página, abre de nuevo la copia descargada y repite el proceso. Revisa las ediciones acumuladas antes de distribuir el archivo final.
¿Cuánto texto personalizado puedo usar?
El texto personalizado admite hasta 30 caracteres. Las entradas largas dentro de ese límite utilizan una letra menor para encajar en el área del sello.
¿Puedo cambiar el tamaño del sello después de colocarlo?
Sí. Ajusta el ancho antes de descargar y utiliza la vista previa para comprobar la escala y la posición respecto al contenido.
¿Se sube mi PDF a un servidor?
No. JavaScript coloca el sello y exporta el PDF dentro de tu navegador.
