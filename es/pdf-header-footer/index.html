Repite información útil en todas las páginas PDF

Escribe un encabezado, un pie o ambos, elige alineación izquierda, central o derecha y aplica el texto en todo el PDF. Los controles de inserción añaden el número actual, el total de páginas o la fecha de hoy sin sintaxis especial. La exportación dibuja contenido nuevo en cada página. El texto existente no se rasteriza intencionalmente, pero el PDF se modifica y sus firmas digitales pueden quedar invalidadas.

Para títulos, fechas, avisos y conteos

  • Repetir un título o nombre de organización en cada página
  • Mostrar una línea como “Página 3 de 12” en vez de un número aislado
  • Identificar un borrador, una copia confidencial o una versión fechada
  • Usar Añadir Números de Página cuando basta un número simple en una esquina

Preguntas frecuentes

¿Cuál es la diferencia con Añadir Números de Página?
Añadir Números de Página está pensado para colocar un único número en una posición estándar. Esta herramienta admite líneas más largas que combinan título, aviso, fecha, página actual y total.
¿Qué formato de fecha inserta {date}?
Inserta la fecha actual como AAAA-MM-DD. Este orden de año, mes y día evita la ambigüedad de las fechas numéricas cortas.
¿Puedo usar diferentes fuentes, colores o negrita?
Esta versión utiliza una fuente predeterminada con el tamaño elegido; no ofrece negrita, varios colores ni logotipos. Usa una marca de agua o un editor PDF adecuado si necesitas un estilo más elaborado.
¿Se sube mi PDF a un servidor?
No. JavaScript añade el texto y reconstruye el PDF localmente en tu navegador.
