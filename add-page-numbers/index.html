Starting number

Add a visible sequence without rebuilding each page

The tool draws a sequential number at the selected position on every page, beginning with the value you enter. Existing text remains selectable in ordinary documents because pages are not rasterized. The PDF itself is still modified, so a digital signature may become invalid and a number can overlap content if the page has little free margin.

Documents that benefit from page references

  • Give printed readers a clear page reference
  • Number a report, contract or manuscript before distribution
  • Continue numbering from an earlier document with a custom starting value
  • Place the sequence consistently at the top or bottom of each page

Frequently asked questions

Does this affect text selectability?
The tool does not rasterize the existing pages, so selectable text normally remains selectable. It does alter the PDF by drawing new content, which can invalidate digital signatures or affect workflows that require a byte-for-byte original.
Can I start counting from a number other than 1?
Yes. Enter the first number you want, and each following page increases the sequence by one.
Can I choose where the number appears?
Yes. Choose top or bottom and align the number left, center or right. Preview pages with different sizes or rotations and check that the number does not cover existing content.
Is my PDF uploaded to a server?
No. JavaScript edits and exports the PDF inside your browser.
