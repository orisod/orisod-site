What does this tool do?

This tool stamps a page number onto every page of your PDF, at the position you choose, starting from whatever number you set. The underlying PDF content stays exactly as it was — text remains selectable, only a number is added to each page.

When should you use it?

  • You're preparing a document for printing and readers need to reference specific pages
  • You're assembling a report, contract, or manuscript that needs page references
  • Your document doesn't start at page 1 (for example, it continues from another document) and you need a custom starting number
  • You want page numbers in a specific corner instead of wherever a printer defaults to

Why use Orisod for this?

You choose exactly where the number goes and where counting starts, then see it applied to every page in one step. Everything happens locally in your browser using pdf-lib — your document is never uploaded to a server.

Frequently asked questions

Does this affect text selectability?
No, the existing PDF content is preserved exactly — only a page number is drawn onto each page.
Can I start counting from a number other than 1?
Yes, set any starting number and the count will continue upward from there across the document.
Can I choose where the number appears?
Yes, pick from six positions — top or bottom, left, center, or right.
Is my PDF uploaded to a server?
No, the entire process happens locally in your browser using JavaScript.
