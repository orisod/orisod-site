What does resizing a PDF do?

Resizing changes the physical page dimensions of a PDF — for example turning a US Letter document into A4, or the reverse. The content on each page is scaled proportionally to fit the new dimensions, so nothing is cropped or cut off; it's stretched or shrunk to match the target size.

When should you use this tool?

  • You received a Letter-sized PDF but need to print it on A4 paper (or vice versa)
  • A document needs to match a specific page size required by a printer or publisher
  • You're standardizing a batch of PDFs from different sources to one consistent size
  • You need a custom page size that isn't one of the standard presets

Frequently asked questions

Will resizing distort my content?
Content is scaled to fit the new page dimensions. If the new size has a different aspect ratio than the original, the content will stretch slightly to fill it — the same trade-off any "resize to fit" tool makes.
Does this change the file size significantly?
Not usually — the underlying content and images aren't recompressed, only the page dimensions and content scale change.
Can I enter a size that isn't in the preset list?
Yes, choose "Custom size…" and enter any width and height in millimeters.
Is my PDF uploaded to a server?
No, the entire process happens locally in your browser using JavaScript.
