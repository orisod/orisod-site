Which pages?

Leave blank to rotate every page, or enter specific pages/ranges (e.g. "1-2, 4").

What does this tool do?

This tool rotates pages inside a PDF by 90°, 180°, or 270°, either across the whole document or only the specific pages you choose. The underlying PDF content stays exactly as it was — text remains selectable and searchable, only the page orientation changes.

When should you use it?

  • A scanned document has one or more pages that came out sideways or upside down
  • You combined pages from different sources with mismatched orientations
  • Only some pages in a document need rotating, not all of them
  • You need to fix orientation before printing or sharing a document

Frequently asked questions

Does this affect text selectability?
No, this only changes the page's rotation metadata — the actual PDF content, including selectable text, stays exactly as it was.
Can I rotate only some pages?
Yes, enter specific page numbers or ranges (like "1-2, 4"), and only those pages will be rotated — the rest stay untouched.
Can I rotate in both directions?
Yes, choose 90° right, 90° left, or a full 180° flip.
Is my PDF uploaded to a server?
No, the entire process happens locally in your browser using JavaScript.
