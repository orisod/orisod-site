How to Make a QR Code for Free (No App Needed)

QR codes are everywhere now — on menus, posters, business cards, packaging — and making one yourself is a lot simpler than the paid apps and subscription services out there would have you believe. Here's what's actually happening inside a QR code, and how to generate one for free in under a minute.

What a QR code actually stores

A QR code is just a visual way of encoding text — that's the whole idea. Most commonly that text is a URL, but it can just as easily be a plain block of text, a phone number, an email address, or a formatted string that tells a phone to join a WiFi network automatically. When a phone camera scans the pattern of black and white squares, it's simply decoding that text back out, the same way a barcode scanner reads a barcode.

Common uses today

  • Restaurant menus — a code on the table links straight to an online menu, skipping a printed one entirely.
  • WiFi sharing — a code encoding your network name and password lets guests connect without typing anything.
  • Business cards and posters — a code linking to a website, portfolio, or contact details, since it's faster than typing a URL by hand.
  • Product packaging — linking to instructions, warranty registration, or additional product information.

Do you need a paid QR code generator?

This is where a lot of confusion (and unnecessary spending) comes from. Some paid services push the idea that free QR codes "expire" or stop working after a trial period — but a standard QR code is just a static image encoding fixed text; there's no server-side component and nothing to expire, ever. What actually "expires" in those services is a dynamic redirect layer they control, where the QR code points to their server, which then forwards you somewhere else — and if you stop paying, that redirect stops working, not the QR code itself. For the vast majority of everyday uses — a link, a WiFi password, a bit of text — a free, static QR code works exactly the same on day one and day one thousand.

Static vs "dynamic" QR codes

The distinction paid services rely on is between static and dynamic codes. A static code has your actual content — the link, the text, the WiFi credentials — baked directly into the pattern, permanently. A dynamic code instead points to a short redirect URL controlled by a company's server, which then forwards the scan to your real destination; this lets the company offer scan analytics and let you change the destination later without reprinting the code, but it also means the code stops working the moment that company's redirect service goes away or your subscription lapses. For a menu, a WiFi network, or a link to a page that won't change, a static code has no such dependency.

A couple of practical tips

QR codes have built-in error correction, meaning they still scan correctly even if part of the pattern is damaged, obscured, or covered by a small logo — which is why you'll sometimes see a company logo sitting in the middle of one. If you're printing a QR code physically, size matters more than people expect: a code that scans fine on a phone screen can be too small to scan reliably once printed on a poster or business card, so it's worth testing a printed version at actual size before mass-printing anything.

Making one in under a minute

Generating a QR code is genuinely simple: type or paste in the text or link you want encoded, and the tool instantly renders the QR pattern as an image you can download and use — print it, add it to a slide, embed it on a website, whatever you need. There's no account to create and no app to install, since the entire process is just converting text into a pattern of squares.

Quick answers

Will my QR code stop working after a while? No — a standard, static QR code encodes the text permanently into the image itself. As long as the underlying link or text stays valid (a URL that still exists, for example), the code will keep working indefinitely.

Can I put a password-protected WiFi network in a QR code? Yes — QR codes support a specific WiFi format that includes the network name and password, letting a phone's camera app join automatically without typing.

Do I need special software to scan one? No — every modern smartphone camera can scan a QR code natively, without a separate app.
