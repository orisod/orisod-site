AVIF Format Explained: How to Open and Convert These Files

If WebP already felt unfamiliar, AVIF is the next format in line — newer, even more efficient, and even less consistently supported. Here's what it actually is and what to do when a .avif file won't open.

What is AVIF?

AVIF (AV1 Image File Format) is an image format built on the same compression technology as the AV1 video codec — an open, royalty-free standard developed by a coalition that includes Google, Netflix, and Mozilla, among others. Its whole purpose is squeezing image data into the smallest possible file at a given quality level, and by most benchmarks it currently does that better than WebP, which in turn already beats JPG.

How much smaller is AVIF, really?

Depending on the image and the compression settings used, AVIF files often come in 20-50% smaller than an equivalent WebP file, and sometimes 50% or more smaller than JPG at comparable visual quality. For a website with heavy image traffic, that's a substantial bandwidth saving on top of what switching to WebP alone would already provide.

Why AVIF compatibility is narrower than WebP's

AVIF is newer, and format support takes time to spread through the entire software ecosystem — browsers, operating systems, photo viewers, editing tools, and everything in between. Every major modern browser now supports AVIF for viewing images on the web, but plenty of desktop software, older devices, and offline tools haven't caught up yet. This is the same compatibility curve WebP went through a few years earlier, just at an earlier point in the process.

Where you'll actually run into AVIF files

  • Saving images from performance-conscious websites — sites chasing every bit of load-time improvement have started serving AVIF to browsers that support it.
  • Some newer phone cameras and apps — a handful of devices and photo apps have started offering AVIF as a storage option, similar to how iPhones defaulted to HEIC.
  • Design and stock photo platforms experimenting with smaller formats — some are offering AVIF downloads to reduce their own bandwidth costs.

Why an AVIF file might not open for you

The same story as any newer format: the software you're using to open the file — an older photo viewer, an editing tool that hasn't updated, an offline app — simply doesn't have an AVIF decoder yet. The file itself is fine; it's a compatibility gap, not a broken download. This is worth remembering before assuming a download failed or a file got corrupted — nine times out of ten with a newer image format, the file is completely intact and the app just hasn't caught up yet.

Should you worry about AVIF becoming the new HEIC problem?

It's a fair comparison — both are efficient formats that occasionally show up unannounced and cause a "why won't this open" moment. The difference is that AVIF's growth is being driven by websites optimizing for speed rather than a single company defaulting every device to it overnight, the way Apple did with HEIC on iPhone. That means AVIF files show up more gradually and less predictably, but the fix is identical either way: convert to something universal when you need the file to work right now, and don't worry about it further.

Converting AVIF to something universal

Rather than tracking down updates for every piece of software you might open the file with, converting the AVIF file to JPG or PNG sidesteps the issue in one step — you get a file that opens absolutely anywhere, at the (usually modest) cost of a larger file size than the AVIF original.

Quick answers

Is AVIF better than WebP? By most measures of compression efficiency, yes, slightly — but WebP currently has broader software support, so which one is "better" depends on whether file size or compatibility matters more for your situation.

Will AVIF eventually replace JPG the way WebP is trying to? It's trending that direction as support spreads, but JPG's near-universal compatibility means it won't disappear from general use anytime soon.

Does converting AVIF to JPG lose much quality? There's a small re-encoding step, same as any format conversion, but at a reasonable quality setting it's not something you'll notice by eye.
