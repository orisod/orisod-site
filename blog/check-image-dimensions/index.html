How to Check an Image's Dimensions and Resolution Online

A form asks for a photo of exactly 600×600 pixels, or a print shop wants 300 DPI, and suddenly you need numbers you don't have. Here's what those terms actually mean and how to check them on any image in seconds.

Pixels, dimensions, and resolution — what's the difference

An image's dimensions are simply its width and height in pixels — a photo that's 4000×3000 has 4000 pixels across and 3000 down. Resolution, usually expressed as DPI (dots per inch), describes how densely those pixels are packed when the image is printed at a physical size. The same 4000×3000 image can look razor-sharp printed small and noticeably soft printed as a poster, because the same pixel count is being stretched across more physical inches.

How DPI and pixel dimensions relate

DPI only means something once you attach a physical size to an image — a pixel count on its own has no inherent print size. For example, a 3000×2000 pixel image printed at 300 DPI comes out at 10×6.67 inches; print that same file at 150 DPI instead and it stretches to 20×13.3 inches, with each pixel now covering more physical space and looking noticeably softer. This is why a print shop asking for "300 DPI" is really asking about the relationship between your pixel count and the size you intend to print at, not a fixed property of the file itself.

Why these numbers actually matter

  • Upload forms for passport photos, ID badges, or profile pictures often require exact pixel dimensions, and reject anything that doesn't match.
  • Social media platforms have specific recommended sizes for cover photos, posts, and thumbnails — get it wrong and the platform crops or stretches your image awkwardly.
  • Print shops typically require a minimum DPI (often 300) at the final print size, or the output comes out blurry.
  • Web developers need to know dimensions to avoid serving an image far larger than it will ever be displayed, which slows down page loads for no visual benefit.

The manual ways to check, and their limits

On a Windows PC, right-clicking a file and opening its Properties will eventually get you the dimensions, buried a couple of tabs in. On a Mac, selecting a file and pressing Cmd+I shows similar information in the Finder's "Get Info" panel. Both work, but only if you're on that specific device with the file already saved locally — neither helps if you're on a phone, checking an image someone just sent you, or trying to verify a photo before you've even downloaded it.

The fastest way: check it in your browser

A browser-based dimension checker skips all device-specific steps. Drop in the image, and it reads the width, height, file format, and often the DPI and aspect ratio directly — no matter what device you're on, and without installing anything. This is particularly useful when you're checking several images in a row against the same requirement, since there's no per-file right-click routine to repeat.

Aspect ratio (the proportional relationship between width and height) matters just as much as raw pixel count: an image with the right total pixels but the wrong ratio still gets awkwardly cropped by most platforms.

Quick answers

What's a good resolution for web use? Web images typically don't need more than 72–150 DPI, since screens display in pixels, not physical inches — DPI only really matters once you're printing.

Does resizing an image change its DPI? Not directly — resizing changes pixel dimensions, while DPI is about how those pixels map to a printed size. The two are related but not the same adjustment.

Can I check dimensions without downloading the file first? If you already have the image open or saved on your device, a browser-based checker reads it locally without needing to upload it anywhere.
