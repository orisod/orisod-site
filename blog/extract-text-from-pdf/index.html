How to Extract Text From a PDF (Copy or Save as .txt)

You need the words inside a PDF — to search them, paste them into an email, or process them with something that only accepts plain text — but retyping a multi-page document by hand isn't a real option. Extracting the text that's already there takes seconds, when the PDF actually has selectable text to extract.

What text extraction actually does

Every page of a text-based PDF stores its content as actual characters, positioned on the page — the same text you can highlight and copy in a PDF viewer. Extraction reads through every page and pulls that text out as plain text, stripping away the fonts, columns and layout and leaving just the words themselves, in reading order.

Why some PDFs give you nothing

A scanned document — a photographed page, or a document run through a scanner — is stored as an image of a page, not as characters. There's no text to extract because there was never any text there to begin with, just pixels that happen to look like letters to a human eye. This is the single most common reason extraction comes back empty, and it's not a bug in the extraction tool — it's a real limitation of what a scanned image contains. Making a scanned document's text extractable requires OCR (optical character recognition), a separate process that recognizes shapes as letters, which plain text extraction doesn't do.

What a good extraction keeps track of

Page boundaries matter even in plain text — knowing where one page ends and the next begins helps you find something later, especially in a long document. A good extraction marks those boundaries clearly in the output rather than running every page's text together into one undifferentiated block.

What gets lost in the process

Plain text extraction is exactly that — plain. Fonts, bold and italic styling, column layout, and table structure aren't preserved, since none of that exists in plain text to begin with. If you need the visual layout intact, extraction isn't the right tool; you'd want to keep working with the PDF itself, or convert it to a format like Word that can hold formatting.

A concrete example

You have a 40-page report and need to search it for every mention of a specific clause — something a PDF viewer's search can sometimes struggle with across a long, image-heavy document. Extracting the full text into one file lets you search or process it with a plain-text tool, or paste specific passages into an email without retyping them.

Quick answers

Why is my extracted text empty or very short? The PDF is likely a scanned image without a real text layer — there's no selectable text to pull out, only pixels. OCR is a separate process for making scanned documents searchable.

Does extraction keep the original formatting? No — it's a plain-text extraction, not a layout-preserving conversion. Fonts, columns and tables aren't preserved.

Can I tell which page a piece of text came from? Yes, if the extraction marks page boundaries in the output — look for page markers rather than one continuous block of text.
