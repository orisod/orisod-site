How to Open a WebP File on Any Device

You saved an image from a website, and instead of opening normally it just... doesn't. The file is a .webp, and whatever app you double-clicked it with has no idea what to do with it. Here's why that happens and how to fix it.

Why the file won't open

WebP is a relatively modern image format, and while every current web browser displays it natively without issue, plenty of desktop and mobile software hasn't caught up. Older versions of Windows Photo Viewer, some versions of macOS Preview, older photo-editing software, and various third-party apps simply don't have a WebP decoder built in. The file itself isn't broken or corrupted — the app you're trying to open it with just doesn't recognize the format.

Where you're most likely to run into this

  • Saving an image from a website — many sites now serve WebP by default, so a routine "save image" can hand you a format your default photo viewer doesn't expect.
  • Receiving a WebP file from someone else — a screenshot tool, a messaging app, or another person's browser may have saved or forwarded it in WebP without either of you choosing that on purpose.
  • Opening it in older design or editing software — some image editors added WebP support later than browsers did, so an outdated version may still lack it.

Option one: update or switch your viewer

On a fairly recent operating system, the built-in photo viewer usually already supports WebP, or a free update or extension adds support. On Windows, a WebP codec extension from the Microsoft Store fixes this for the default Photos app. On a Mac, recent versions of Preview handle WebP natively; only older macOS versions have trouble. This route means you can keep working with the original WebP file as-is, which is worth doing if you plan to keep using it on the web where WebP's smaller size is an advantage.

Option two: convert it to a format that just works

If updating software isn't practical — you don't have admin rights, you're on a device you don't control, or you just need the image to open right now — converting the WebP file to PNG (or JPG) sidesteps the problem entirely. PNG is a natural target for this specifically because it preserves transparency if the original WebP had any, matching WebP's own capability rather than losing it, which converting to JPG would do.

Which option makes more sense

If it's a one-off image you need to open right now, converting is faster and doesn't require installing anything. If you're routinely receiving or working with WebP files, updating your software to support the format natively saves you from repeating the conversion every time. Most people end up doing a bit of both: converting when they urgently need a specific file to open, and eventually updating their software once the friction becomes annoying enough.

What about opening WebP on a phone?

Both modern Android and iOS handle WebP fine in their default photo apps and browsers — this issue shows up almost entirely on desktop software, particularly older versions of Windows or macOS, or standalone apps that haven't been updated recently. If a WebP file opens fine on your phone but not your computer, that's a strong sign the fix is on the computer side, not the file.

Quick answers

Is a WebP file that won't open actually corrupted? Almost never — the far more common explanation is simply that the software you're using doesn't have WebP support yet, not that anything is wrong with the file.

Will converting WebP to PNG lose the transparency? No — PNG supports transparency just like WebP does, so a transparent WebP converts to a transparent PNG with nothing lost on that front.

Why did I get a WebP file when I didn't ask for one? Many websites now serve images as WebP by default for performance reasons, so a normal "save image" from a browser increasingly hands you a WebP file whether you intended that or not.
