How to Edit a PDF Online (Text Boxes, Highlights, and Markup)

Marking up a PDF — highlighting a key sentence, striking through an old figure, dropping in a note — doesn't need a full desktop editor. In the browser, the same real text that lets you copy-paste from a PDF is exactly what lets a highlight land precisely on the right words, and understanding that distinction explains both what this kind of tool can do and where it genuinely can't.

Highlighting works by using text you can already select

Underneath a rendered PDF page, the actual words exist as real, positioned text — the same text a "select all, copy" would grab in any PDF viewer. A browser-based markup tool renders the page as an image for you to look at, and quietly overlays that same real text, invisibly, in exactly the right spots so you can drag your mouse across it and select it the normal way. Once you've selected a word or a sentence, the browser already knows precisely where every character sits — that position is what gets turned into a highlight, an underline, or a strikethrough.

Text boxes work differently — and always work

A text box doesn't depend on any of that. Click anywhere on the page, type, and that note gets placed at the exact pixel you clicked, regardless of whether the page underneath has real text at all. That's why a text box is the one markup type that works on literally any PDF, including a scanned one, while highlighting a passage of text requires that passage to actually exist as text in the file.

What a scanned PDF needs first

A scan or a photographed page is, to the browser, just a picture — there's no real text underneath to select, so highlighting, underlining, and striking through have nothing to attach to. A markup tool built around real text selection should say so plainly rather than faking a highlight in roughly the right place. The fix is the same one that makes a scan searchable in the first place: running it through OCR first adds a real, invisible, selectable text layer under the image, after which highlighting works exactly the same as on a native PDF.

Undoing a mistake

Nothing should be permanent until you actually finish. A markup tool that draws changes directly into the file the moment you make them punishes every small mistake; the better shape is a running list of everything you've added, each one removable on its own, with nothing baked into the real PDF until you explicitly save.

Quick answers

Can I highlight a sentence that spans two lines? Yes — dragging across a line break selects both lines, and each line gets its own correctly-positioned highlight or underline.

Will my highlights and text boxes still be there if I open the file in another PDF viewer? Yes — once saved, they're drawn directly into the page as permanent content, not a separate layer that depends on this tool to display.

Does adding a highlight change the PDF's actual text? No — a highlight or underline is drawn on top of the page; the original text underneath stays exactly as it was, still searchable and selectable.
