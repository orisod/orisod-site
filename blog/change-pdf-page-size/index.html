How to Change a PDF's Page Size (A4, Letter, Legal or Custom)

You received a PDF sized for US Letter paper, but you're printing on A4 — or the other way around. The content is fine, the file just isn't sized for the paper you actually have. Resizing an existing PDF's pages takes one pass; redesigning the document to a different page size from scratch doesn't need to happen.

Why this mismatch happens so often

Letter (used mainly in the US and Canada) and A4 (used almost everywhere else) are close in size but not identical — Letter is slightly wider and shorter, A4 slightly narrower and taller. A document created in one region and opened in another routinely carries the "wrong" page size for whoever's printing it, and the same mismatch shows up with Legal-sized paper for contracts or forms.

What resizing actually does

Resizing changes a PDF's physical page dimensions and scales the content on each page proportionally to fit the new size — nothing is cropped or cut off, it's stretched or shrunk to match. If the new page has a different aspect ratio than the original (which A4 and Letter do, slightly), the content stretches a little to fill it rather than leaving blank strips — the same trade-off any "resize to fit" approach makes.

Standard sizes vs. custom dimensions

A4, Letter and Legal cover most cases, but a custom width and height is sometimes necessary — a printer with specific size requirements, a non-standard booklet format, or a page size that isn't part of the usual presets. Either way, the underlying operation is the same: define a target width and height, and every page in the document gets scaled to match it.

What doesn't change

The number of pages, their order, and their content all stay exactly as they were — only the physical dimensions and the scale of what's on each page change. File size typically stays close to the original too, since images and embedded content aren't recompressed, just redrawn at a new scale.

A concrete example

A US-based client sends you a Letter-sized contract to sign and return, but your printer is loaded with A4 and keeps producing a slightly cropped or oddly-margined page. Rather than fighting printer settings, resizing the PDF to A4 before printing gets you a page that matches the paper in the tray, with everything scaled to fit properly.

Quick answers

Will resizing distort my content? Slightly, if the target size has a different aspect ratio than the original — the same stretch-to-fit trade-off any resize tool makes. Between A4 and Letter, the difference is small enough to rarely be noticeable.

Does this affect file size much? Not usually — the underlying content isn't recompressed, only the page dimensions and content scale change.

Can I use a size that isn't A4, Letter or Legal? Yes, most resizing tools support a custom width and height alongside the standard presets.
