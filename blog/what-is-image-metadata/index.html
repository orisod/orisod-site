What Is Image Metadata and How to View It

An image file can store information that never appears in the picture itself. Depending on the format and software involved, it may include camera settings, dates, location, captions, ownership details, and editing data.

Image metadata goes beyond EXIF

EXIF is the best-known standard because phones and cameras use it for settings, timestamps, and sometimes GPS coordinates. IPTC was developed for news and publishing workflows and commonly stores captions, keywords, credits, and rights information. XMP can hold similar descriptive data along with extensible fields used by editing and asset-management software. One image may contain information from several of these standards at the same time.

What each type of metadata typically contains

Metadata typeMaintained byTypically stores
EXIFCIPA/JEITA (Exif 3.0, 2023)Camera make/model, exposure settings, capture date & time, often GPS coordinates
IPTCIPTC Photo Metadata StandardCaption, keywords, creator/byline, copyright notice, credit, location as text
XMPISO 16684-1 (originally Adobe)A container format — commonly holds IPTC's own fields ("IPTC-in-XMP"), plus editing history and app-specific data

This overview reflects CIPA Exif 3.0 (2023), the IPTC Photo Metadata Standard, and ISO 16684-1:2019 for XMP as checked in August 2026. Each specification contains additional fields beyond the examples shown here.

  • EXIF — camera make and model, exposure settings, date and time captured, and often GPS coordinates on phone photos.
  • IPTC — caption or description, keywords, photographer credit, copyright notice, and sometimes location described in text (city, country) rather than coordinates.
  • XMP — similar descriptive fields to IPTC, plus editing history in some software, and custom fields specific to certain applications.

Why image files store metadata

Metadata keeps context attached to the file. A publication can read IPTC captions and credits when a photographer delivers an image. A photo manager can use EXIF dates and camera details to organize a library. Editing software may store workflow information in XMP. The data remains invisible during ordinary viewing, but other applications can read and use it.

Where metadata becomes useful to check

  • Verifying a photo's origin — checking the camera model and timestamp to confirm when and how an image was actually captured.
  • Checking usage rights before reusing an image — IPTC copyright and credit fields can indicate whether and how an image is licensed for reuse.
  • Understanding camera settings — photographers reviewing their own EXIF data to learn what settings produced a particular result.
  • Privacy review before sharing — checking whether GPS or other identifying data is embedded before posting a photo publicly.

Viewing and removing are separate actions

A viewer reads the fields without changing the file. Removal creates a copy with selected metadata stripped out. Check the contents first, then decide whether useful credits or descriptions should remain and whether private fields such as location should be removed before sharing.

How to inspect an image

Open the file in a metadata viewer to list the EXIF, IPTC, and XMP fields it contains. The results may include camera details, dates, descriptions, and coordinates. Viewing is read-only, so the image and its embedded information remain unchanged.

Checking the date and camera details

Suppose a photo is described as recent, but its metadata reports an older capture date. That difference is worth investigating, although it is not proof by itself. Device clocks can be wrong, software can rewrite fields, and metadata can be edited or removed. Treat it as supporting information rather than a guarantee of authenticity.

Questions about image metadata

Does every image contain metadata? No. Screenshots and exported graphics may contain little or none, while an original camera or phone photo often includes several fields.

Does viewing change the file? No. A metadata viewer reads the fields without altering the image.

Can metadata be inaccurate? Yes. Device settings, editing software, exports, and messaging platforms can change or remove fields. Use metadata as evidence with limitations, not as unquestionable proof.
