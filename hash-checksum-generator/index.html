What does this tool do?

Type or paste text, or drop in a file, and this tool computes its MD5, SHA-1, SHA-256, SHA-384, and SHA-512 hashes all at once — no need to guess which algorithm a published checksum uses. Paste an expected hash into the verify field and it's checked automatically against whichever of the five matches its length.

When should you use this tool?

  • Confirming a downloaded file matches the checksum its publisher listed
  • Generating a checksum to share alongside a file you're distributing
  • Comparing two files for byte-for-byte equality without opening either one
  • Computing a quick hash of a text snippet or password for reference

Why Orisod

SHA-1, SHA-256, SHA-384, and SHA-512 are computed with the browser's native Web Crypto API. MD5 isn't part of that API (it was deliberately left out of the spec), so it's computed with SparkMD5 instead. Nothing you type or upload ever leaves your browser.

Frequently asked questions

Is MD5 or SHA-1 safe to use?
Not for security purposes — both have known collision weaknesses and shouldn't be used for passwords or digital signatures. They're included here because file-integrity checks (confirming a download wasn't corrupted) still commonly publish MD5 or SHA-1 checksums, which is a different, non-adversarial use case.
How does the verify field know which algorithm to check?
Each hash algorithm always produces a fixed length of output (MD5 is 32 hex characters, SHA-1 is 40, and so on), so the tool matches your pasted hash's length to the right algorithm automatically.
Is there a file size limit?
No hard limit, but the whole file is read into memory to compute the hashes, so extremely large files (multiple gigabytes) may be slow or run into your browser's memory limits.
Is my file or text uploaded to a server?
No, the entire process happens locally in your browser using JavaScript.
