Favicon Generator

Upload a square image (a logo works best) and get a complete favicon package: favicon.ico plus every standard size for browsers, iOS, and Android. Everything happens locally in your browser.

🔒 Processed on your device · No upload · No account · No watermark

Square images work best. Non-square images will be cropped to a centered square.

One source image, several favicon files

Choose an image to create a multi-resolution favicon.ico, separate browser PNGs, an Apple touch icon and Android Chrome icons. The download packages those files with an HTML snippet in one ZIP. Each output is rasterized at a fixed size, so a simple source with strong contrast usually remains clearer than fine text or intricate artwork.

Prepare icons for browsers and home screens

  • Add a favicon package to a new website
  • Replace a single blurry icon with several appropriate sizes
  • Provide icons for iOS and Android home-screen shortcuts
  • Regenerate the package after a logo update

Frequently asked questions

What sizes are included in the package?
The ZIP includes favicon.ico with 16×16 and 32×32 entries, favicon-16x16.png, favicon-32x32.png, apple-touch-icon.png at 180×180, and Android Chrome PNGs at 192×192 and 512×512.
What if my image isn't square?
The source is center-cropped to a square before resizing, which avoids stretching but can remove content near the longer edges. Preview the crop and add padding to the source if the subject needs more room.
How do I add these to my website?
Place the files where the supplied paths can resolve, then add the included HTML snippet inside the site’s <head>. If you use another folder or framework, adjust the href paths and clear browser caches when testing.
Is my image uploaded anywhere?
No. JavaScript crops, resizes and packages the image inside your browser.
